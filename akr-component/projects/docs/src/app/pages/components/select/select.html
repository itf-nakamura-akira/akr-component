Select

A customizable select component.

Basic Usage

Disabled Options

Individual options can be disabled by setting the disabled property.

Disabled Select

The entire select component can be disabled by setting the disabled property or via Reactive Forms.

Selection Event

The selectionChange event is emitted whenever the selected value changes.
